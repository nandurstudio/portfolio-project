# Prompt Gemini - Flow Voting Pemilihan Ketua Koperasi

Gunakan prompt di bawah ini langsung di Gemini untuk generate gambar flow proses voting.

## Prompt Utama (Siap Copy-Paste)

Buatkan **infografik flowchart vertikal** berbahasa Indonesia dengan judul:

**"FLOW VOTING PEMILIHAN KETUA KOPERASI"**

Gaya visual:
- Modern, clean, corporate, mudah dipahami anggota koperasi.
- Warna dominan biru-putih dengan aksen hijau (aman, terpercaya, profesional).
- Gunakan ikon sederhana untuk setiap langkah (email, OTP, NIK, site, GoPay, vote, voucher, selesai).
- Tampilkan nomor langkah besar (1 sampai 9).
- Ukuran teks jelas, kontras tinggi, cocok untuk poster A4 dan posting sosial media.
- Tambahkan panah penghubung antar langkah.
- Untuk langkah keputusan, gunakan bentuk diamond (YA / TIDAK).
- Tambahkan catatan penting berikon warning pada langkah konfirmasi vote.

Konten flow yang harus ditampilkan persis:

1. **Kunjungi Website Voting**
   - Buka: **https://kkmsmartvote.web.id**
   - Vote akan di buka pada tanggal tertera di website.

2. **Masukkan NIK (Wajib)**
   - Nama dan Department terisi otomatis.

3. **Pilih Site**
   - Pilih Site dari menu dropdown.

4. **Masukkan Email**
   - Email boleh email Kalbe atau Gmail.
   - Email akan dipakai untuk menerima OTP.

5. **Request OTP & Verifikasi OTP**
   - Klik tombol Request OTP.
   - Masukkan kode OTP yang dikirim ke email.

6. **Lanjut VOTE + Konfirmasi Final**
   - Klik VOTE.
   - Tampilkan checkbox/konfirmasi:
     **"Apakah Anda yakin? Vote tidak dapat diubah."**
   - Beri penekanan visual bahwa aksi final tidak bisa diubah.

7. **Setelah Vote Berhasil: Masukkan Nomor HP GoPay**
   - Nomor HP harus terhubung GoPay.
   - Jika tidak punya GoPay pribadi, boleh menggunakan GoPay keluarga.

8. **Konfirmasi Nama GoPay** (Decision / Percabangan)
   - Pertanyaan: "Apakah nama di GoPay sama dengan nama Anda?"
   - Cabang **YA** -> lanjut simpan data GoPay.
   - Cabang **TIDAK** -> wajib isi **Nama Penerima GoPay**, lalu simpan data GoPay.

9. **Berhasil VOTED -> Hak Redeem Voucher**
   - Setelah berhasil vote, pemilih berhak redeem voucher GoPay **Rp25.000** ke Admin.
   - Voucher mengikuti nama pada poin 8 (nama pemilik/penerima GoPay yang dikonfirmasi).

10. **Selesai**
   - Tampilkan status akhir: voting sukses dan proses selesai.

Tambahan layout:
- Tambahkan subjudul kecil di bawah judul: "Panduan singkat proses voting anggota koperasi".
- Tambahkan badge kecil: "AMAN • CEPAT • TRANSPARAN".
- Pastikan alur terbaca jelas dari atas ke bawah.

## Prompt Alternatif (Versi Singkat)

Buat infografik flowchart vertikal berbahasa Indonesia berjudul "FLOW VOTING PEMILIHAN KETUA KOPERASI" dengan 10 langkah: (1) kunjungi website https://kkmsmartvote.web.id, (2) input NIK wajib lalu nama+department auto-fill, (3) pilih site dropdown, (4) input email Kalbe/Gmail, (5) request OTP dan verifikasi OTP, (6) klik vote dengan konfirmasi "Apakah Anda yakin? Vote tidak dapat diubah.", (7) setelah vote berhasil input nomor HP GoPay (boleh GoPay keluarga), (8) decision: "Apakah nama GoPay sama dengan nama Anda?" YA simpan langsung, TIDAK isi nama penerima GoPay, (9) berhak redeem voucher GoPay Rp25.000 ke admin sesuai nama pada langkah 8, (10) selesai. Gunakan gaya modern, bersih, corporate, warna biru-putih dengan aksen hijau, ikon per langkah, nomor besar, panah jelas, dan teks mudah dibaca.
